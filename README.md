# FileCodec

Веб-приложение для шифрования и дешифрования файлов прямо в браузере.  
Файлы **никуда не отправляются** - всё происходит локально через Web Crypto API.

**[Открыть приложение](https://ТВО_НИК.github.io/file-codec/)**

---

## Возможности

- 🔒 Шифрование / дешифрование любых файлов
- 📁 Несколько файлов одновременно с выбором через чекбоксы
- 🖱️ Drag & Drop или клик для добавления файлов
- 🔍 Автоопределение режима - файлы `.fcd` дешифруются автоматически
- 👁️ Встроенный предпросмотр расшифрованных файлов (изображения, видео, аудио, PDF, текст/код)
- 🖼️ Модальное окно с навигацией между файлами и стрипом миниатюр
- ⬇️ Скачивание отдельных файлов или всех сразу одной кнопкой
- 🔁 Повторная попытка для файлов с ошибкой без повторного добавления
- 🎲 Генератор случайного пароля
- 💪 Индикатор стойкости пароля
- 📋 История операций в памяти сессии
- 🧹 Принудительная очистка буферов после скачивания
- 📱 PWA - устанавливается как приложение, работает офлайн

## Безопасность

| Параметр | Значение |
|----------|----------|
| Алгоритм | AES-GCM 256 |
| Деривация ключа | PBKDF2, SHA-256 |
| Итерации PBKDF2 | 600 000 (рекомендация OWASP 2023) |
| Salt | 16 байт, случайный для каждого файла |
| IV / Nonce | 12 байт, случайный для каждого файла |
| Аутентификация | GCM auth tag - при неверном пароле сразу ошибка |

### Формат зашифрованного файла `.fcd`

```
[0..15]   Salt       - 16 байт
[16..27]  IV/Nonce   - 12 байт
[28..]    Ciphertext - N байт (включает 16-байтный GCM auth tag)
```

Salt и IV встроены в файл - для дешифровки нужен только пароль.

### Очистка памяти

- Входной буфер обнуляется (`fill(0)`) сразу после операции
- Выходной буфер обнуляется через 3 секунды после скачивания
- `URL.revokeObjectURL` вызывается до обнуления буфера
- При закрытии или удалении карточки буферы и URL зачищаются немедленно

## Предпросмотр

Поддерживаемые форматы для встроенного предпросмотра:

| Тип | Форматы |
|-----|---------|
| Изображения | `png` `jpg` `jpeg` `gif` `webp` `svg` `bmp` `avif` `ico` |
| Аудио | `mp3` `wav` `ogg` `flac` `aac` `m4a` `opus` `weba` |
| Видео | `mp4` `webm` `ogv` `mov` |
| PDF | `pdf` |
| Текст / код | `txt` `md` `json` `csv` `log` `xml` `yaml` `yml` `toml` `ini` `ts` `js` `html` `css` `sh` `py` `rs` `go` `java` `c` `cpp` |

Остальные форматы скачиваются автоматически без предпросмотра.

## Стек

- **Vite 5** + **TypeScript** (strict mode)
- **Web Crypto API** - встроен в браузер, нет внешних крипто-зависимостей
- **vite-plugin-pwa** - Service Worker, офлайн-режим, установка как PWA
- Нет UI-фреймворков, нет рантайм-зависимостей

## Локальная разработка

```bash
git clone https://github.com/ТВО_НИК/file-codec.git
cd file-codec
npm install
npm run dev
```

Приложение доступно на `http://localhost:5173/file-codec/`
