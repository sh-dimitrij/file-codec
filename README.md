# FileCodec

Шифрование и дешифрование файлов прямо в браузере.
Файлы **никуда не отправляются** — всё происходит локально через Web Crypto API.

## Стек

- **Vite 5** + **TypeScript** (строгий)
- **Web Crypto API** — AES-GCM 256, PBKDF2 (600 000 итераций, SHA-256)
- **vite-plugin-pwa** — работает офлайн после первого открытия
- Без фреймворков, без зависимостей в рантайме

## Формат зашифрованного файла

```
[0..15]  Salt      — 16 байт, случайный
[16..27] IV/Nonce  — 12 байт, случайный  
[28..]   Ciphertext — N байт (включает 16-байтный GCM auth tag)
```

## Возможности

- Шифрование / дешифрование нескольких файлов одновременно
- Drag & Drop
- Автоопределение режима (`.fcd` → дешифровать)
- SHA-256 хэш входного и выходного файла
- Предпросмотр изображений и текстовых файлов после расшифровки
- Генератор случайного пароля
- Индикатор стойкости пароля
- История операций (в памяти сессии)
- PWA — устанавливается как приложение

## Разработка

```bash
npm install
npm run dev
```

## Сборка и деплой

```bash
npm run build   # → dist/
```

Деплой на GitHub Pages происходит автоматически через GitHub Actions
при каждом пуше в ветку `main`.

Приложение будет доступно по адресу:
`https://<username>.github.io/file-codec/`

### Первый деплой

1. Создай репозиторий `file-codec` на GitHub
2. В Settings → Pages → Source выбери **GitHub Actions**
3. Запушь код — Actions сделают всё остальное

## Безопасность

- Ключ выводится через PBKDF2 с 600 000 итерациями (рекомендация OWASP 2023)
- AES-GCM обеспечивает аутентификацию данных — при неверном пароле или порче файла выдаётся ошибка
- Salt и IV генерируются заново для каждого файла
- Входной буфер обнуляется после операции (`wipeBuffer`)
